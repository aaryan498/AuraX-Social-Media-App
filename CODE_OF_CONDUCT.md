# Code of Conduct

## Our Pledge

We are committed to making participation in AuraX a respectful, inclusive, and collaborative experience for everyone, regardless of background, identity, experience level, nationality, or skills.

Our goal is to foster an open-source environment where contributors can learn, collaborate, and grow together while building meaningful software that connects people worldwide.

---

# Expected Behavior

Contributors are expected to:

- Use respectful and professional communication
- Be welcoming to contributors of all experience levels
- Provide constructive feedback during discussions and code reviews
- Respect differing opinions and technical perspectives
- Focus on collaboration and project improvement
- Maintain patience and professionalism during discussions
- Ask questions whenever requirements or expectations are unclear
- Support a positive and growth-oriented community environment
- Celebrate contributions and successes of others
- Help new contributors feel welcome and supported

---

# Unacceptable Behavior

The following behaviors are unacceptable within the AuraX community:

- Harassment, discrimination, or hate speech
- Personal attacks, insults, or intimidation
- Toxic, hostile, or disruptive behavior
- Publishing private or confidential information without permission
- Spam, trolling, or intentionally misleading contributions
- Repeatedly ignoring project guidelines or maintainer instructions
- Sharing credentials, secrets, API keys, or sensitive information publicly
- Any behavior that could make contributors feel unsafe, unwelcome, or uncomfortable
- Sexual harassment or unwanted sexual advances
- Deliberate sabotage of project or other contributors' work

---

# Contribution Standards

All contributors are encouraged to:

- Follow repository contribution guidelines (see CONTRIBUTING.md)
- Keep discussions constructive and project-focused
- Submit meaningful and well-tested contributions
- Respect maintainers, reviewers, and fellow contributors
- Maintain professionalism in issues, pull requests, and discussions
- Help others learn and grow in the community
- Acknowledge and learn from mistakes
- Work collaboratively to resolve conflicts

---

# Enforcement

Project maintainers are responsible for enforcing this Code of Conduct.

Maintainers may take appropriate action against unacceptable behavior, including:

- Warning contributors about problematic behavior
- Removing offensive comments or discussions
- Closing disruptive issues or pull requests
- Rejecting contributions that violate this code
- Temporarily restricting participation
- Permanently banning from the project

Enforcement decisions will be made with fairness and in the best interest of maintaining a healthy community environment.

---

# Reporting Issues

If you experience or witness unacceptable behavior, please report it respectfully through:

- **Email**: Contact project maintainers privately
- **GitHub Issues**: Create a confidential security/conduct issue
- **Discussions**: Use private messages if available

**How to Report:**

1. Describe the incident in detail
2. Include dates and timestamps
3. Provide relevant links or context
4. Explain impact of the behavior
5. Suggest any resolutions if appropriate

All reports will be reviewed carefully and handled appropriately with confidentiality maintained where appropriate.

---

# Scope

This Code of Conduct applies to all project spaces, including:

- GitHub issues and pull requests
- GitHub discussions and comments
- Project documentation
- Community interactions
- Official communication channels (email, Discord, etc.)
- Social media representing the project
- External events or conferences
- Private communications between contributors

# Community Values

We are committed to fostering a community that values:

### Inclusivity

Everyone's perspective is valuable regardless of background or experience. We celebrate diversity and actively work to make everyone feel welcome.

### Respect

We treat all contributors with dignity and respect. Disagreement doesn't mean disrespect. We can have different opinions while maintaining professional relationships.

### Collaboration

Working together achieves more than working alone. We believe in collective problem-solving and supporting each other's growth.

### Learning

Growth through knowledge sharing and continuous improvement. We encourage asking questions and learning from mistakes.

### Excellence

Pursuing quality in all contributions. We strive for high standards in code, documentation, and communication.

### Transparency

Clear and honest communication about decisions, challenges, and opportunities. We believe in open dialogue and shared understanding.

# Acknowledgement

By participating in AuraX, contributors agree to:

- Follow this Code of Conduct
- Help maintain a positive and respectful open-source environment
- Report violations when witnessed
- Support the community in upholding these values

Together, we can build a welcoming community that fosters innovation and supports each other in creating amazing software that improves how people connect and communicate.
